# ORANGE EventWorks website

Website source for [ORANGE EventWorks](https://orangeeventworks.co.uk/).

Development uses a demo-first deployment flow:

- `develop` → `https://orangeeventworks.co.uk/demo/`
- `main` → `https://orangeeventworks.co.uk/`

The production and demo PHP configuration files are deliberately kept outside `public_html` and are not stored in GitHub.

The full deployment and Hostinger setup notes are maintained on the `develop` branch until the first production release.
